# Add a Blazor Linear Gauge to a Blazor Server App

This project demonstrates how to create and configure a **Syncfusion Blazor Linear Gauge** within a **Blazor Server** application. It focuses on the essential setup and customization steps required to render a functional linear gauge component and adjust its visual and functional properties.

### Project Overview

The sample application walks through integrating the Syncfusion Blazor Linear Gauge component into a Blazor Server app. It illustrates how to initialize the gauge, configure its axis, and customize visual elements such as pointer values, axis line dimensions, and ranges. The goal is to provide a clear and practical reference for developers who want to understand the basics of working with linear gauges in Blazor.

### Key Features

- Integration of Syncfusion Blazor Linear Gauge in a Blazor Server app  
- Configuration of axis pointer values  
- Customization of axis line height and width  
- Definition and display of multiple axis ranges  
- Simple and focused setup suitable for learning and reference  

### Prerequisites

- Visual Studio 2022  
- .NET SDK compatible with Blazor Server  
- Basic understanding of Blazor and C#  

### How to Run the Project

1. Clone or download this repository to your local machine.  
2. Open the solution file using **Visual Studio 2022**  
3. Restore the required NuGet packages by rebuilding the solution.  
4. Run the project to launch the Blazor Server application.  

### Usage

Once the application is running, the Linear Gauge is rendered as part of the UI. You can review the source code to understand how axis values, pointers, and ranges are defined and modified. This makes it easier to adapt the sample for real-world dashboards or monitoring scenarios.
